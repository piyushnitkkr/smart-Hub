# 📖 Smart Study Hub

🚀 **Smart Study Hub** is an all-in-one academic resource platform designed to help university students **collaborate, organize, and access** study materials efficiently.

## 🌟 Features
- **📚 Organized Resources** – Access branch & semester-specific study materials effortlessly.
- **💬 Real-time Chat** – Collaborate seamlessly with peers using live messaging powered by **Socket.IO**.
- **🔍 Advanced Search** – Quickly find resources with filtering and search functionality.
- **🎨 Responsive UI** – A sleek, dark-themed interface with a **purple accent** for a focused learning experience.
- **🔐 Secure & Reliable** – Built with **RESTful APIs** for smooth material sharing and user authentication.

## 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS, shadcn/ui
- **Backend**: Node.js, Express.js, MongoDB
- **Real-time Features**: Socket.IO

## 🚀 Getting Started
### 🔧 Prerequisites
Make sure you have **Node.js** and **MongoDB** installed on your system.

### 🛠️ Installation & Setup
1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/smart-study-hub.git
   cd smart-study-hub
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Set up environment variables in a `.env` file:
   ```env
   PORT=5000
   MONGO_URI=your_mongodb_connection_string
   ```
4. Start the backend server:
   ```sh
   npm run server
   ```
5. Navigate to the `client` directory and start the frontend:
   ```sh
   cd client
   npm start
   ```
